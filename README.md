# Job Hunt Journal

Markdown-based daily job search tracker, rendered as a docs site with [mdBook](https://rust-lang.github.io/mdBook/) and hosted on Cloudflare Pages.

## Daily workflow

```bash
./today.sh    # create today's log, auto-updates sidebar, opens in VS Code
./stats.sh    # print totals in the terminal
```

## Preview locally

```bash
# Install mdBook once
cargo install mdbook
# or: brew install mdbook

mdbook serve  # opens http://localhost:3000
```

## Deploy to Cloudflare Pages

1. Push this repo to GitHub
2. In Cloudflare Pages → **Create a project** → connect the repo
3. Set:
   - **Build command:** `bash build.sh`
   - **Build output directory:** `book`
4. Deploy — every `git push` auto-deploys

## Project structure

```
src/
├── README.md          ← overview page
├── SUMMARY.md         ← sidebar nav (auto-generated by today.sh)
└── logs/
    └── YYYY-MM-DD.md  ← one file per day
book.toml              ← mdBook config
template.md            ← daily log template
today.sh               ← run each morning
stats.sh               ← terminal stats
build.sh               ← Cloudflare Pages build script
```
